# ⚡ LEGENDARY AGE v0.3 — ВСЕ КОМАНДЫ И ИНСТРУКЦИИ

## 🚀 СНАЧАЛА УСТАНОВИ NODE.JS

Переходи на https://nodejs.org и скачай **LTS версию**.

Проверь что установилось:
```bash
node --version
npm --version
```

Должно вывести версии (например v20.10.0)

## 📦 ШАГИ УСТАНОВКИ ПОСЛЕ РАСПАКОВКИ АРХИВА

### Шаг 1: Перейди в папку проекта
```bash
cd la2
```

### Шаг 2: Установи все зависимости
```bash
npm install
```

**Это займёт 1-3 минуты. Жди появления папки `node_modules/`**

---

## 🎮 ЗАПУСК ИГРЫ

### ВАРИАНТ 1: Лаунчер + Сервер вместе (РЕКОМЕНДУЕТСЯ)

Самый простой способ для первого раза:

```bash
npm run start:local
```

**Что произойдёт:**
1. Откроется окно лаунчера
2. Сервер запустится в фоне автоматически
3. Ты сможешь создать персонажа
4. Запустить игру

**Останови:** Закрой окно лаунчера (он закроет и сервер)

---

### ВАРИАНТ 2: Сервер и Лаунчер раздельно

Если хочешь контролировать отдельно:

**Терминал 1 (Сервер):**
```bash
npm run server
```

**Должно вывести:**
```
🎮 Legendary Age Server v0.3
📡 WebSocket: ws://localhost:8080
✅ Database initialized
```

**Терминал 2 (Лаунчер):**
```bash
npm start
```

**Останови сервер:** Нажми `Ctrl + C` в терминале

---

## 🌍 ЗАПУСК СЕРВЕРА ДЛЯ ДРУЗЕЙ

### На ЛОКАЛЬНОЙ СЕТИ (в одной сети, например дома)

**На твоём компе:**
```bash
npm run server
```

**Узнай свой IP адрес:**

Windows:
```bash
ipconfig
```
Ищешь строку "IPv4 Address: 192.168.x.x"

Mac/Linux:
```bash
ifconfig
```

**У друга в лаунчере:**
- Нажми "Онлайн" режим
- В поле "Сервер" введи:
```
ws://твой_IP:8080
```

Например:
```
ws://192.168.1.100:8080
```

## ☁️ ЗАПУСК СЕРВЕРА В ИНТЕРНЕТЕ (Railway.app)

### Шаг 1: Загрузи код на GitHub

```bash
# Инициализируй Git репо
git init

# Добавь все файлы
git add .

# Сделай первый коммит
git commit -m "Legendary Age v0.3"

# Создай репо на https://github.com/new
# Назови его: legendary-age-v0.3

# Загрузи код (замени на твой username)
git remote add origin https://github.com/ТВ_USERNAME/legendary-age-v0.3.git
git branch -M main
git push -u origin main
```

GitHub попросит логин/пароль:
- **Логин:** твой GitHub username
- **Пароль:** Personal Access Token (см. ниже)

**Получить токен:**
1. Переходи на https://github.com/settings/tokens
2. Нажми "Generate new token (classic)"
3. Выбери права: `repo` и `admin:repo_hook`
4. Нажми "Generate token"
5. **Копируй токен** (больше не увидишь!)
6. Используй как пароль

---

### Шаг 2: Запусти на Railway.app

1. Переходи на https://railway.app
2. Нажми "Sign Up" → логин через GitHub
3. Нажми "New Project" → "Deploy from GitHub"
4. Выбери твой репо `legendary-age-v0.3`
5. Railway автоматически запустит сервер (ждёшь 3-5 минут)

---

### Шаг 3: Получи URL сервера

Railway выдаст адрес вроде:
```
https://legendary-age-v0.3-production.railway.app
```

Для WebSocket (в лаунчере) используй:
```
wss://legendary-age-v0.3-production.railway.app
```

---

### Шаг 4: Обнови лаунчер

Открой `index.html` в текстовом редакторе и найди:
```html
<input type="text" id="in-server" value="ws://localhost:8080"
```

Замени на:
```html
<input type="text" id="in-server" value="wss://legendary-age-v0.3-production.railway.app"
```

Сохрани файл.

---

### Шаг 5: Собери новый .exe (для друзей)

```bash
npm run build
```

Когда завершится, в папке `dist/` появится:
```
Legendary Age 0.3.0.exe
```

Раздай этот файл друзьям! Они просто запустят .exe без установки.

## 📊 КОНФИГУРАЦИЯ СЕРВЕРА

### Изменить порт (если 8080 занят)

```bash
PORT=3000 npm run server
```

Тогда лаунчер должен подключаться к:
```
ws://localhost:3000
```

### Изменить хост (слушать конкретный IP)

```bash
HOST=127.0.0.1 npm run server
```

По умолчанию: `0.0.0.0` (слушает все интерфейсы)

### Объединить в одну команду

```bash
PORT=3000 HOST=0.0.0.0 npm run server
```

## 🧪 ПРОВЕРКА ЧТО РАБОТАЕТ

### Сервер запустился?

При `npm run server` должно быть:
```
🎮 Legendary Age Server v0.3
📡 WebSocket: ws://localhost:8080
✅ Database initialized
✅ Listening on port 8080
```

### Лаунчер подключился?

В лаунчере должно быть:
```

```

Если написано "❌ Ошибка подключения":
1. Проверь что сервер запущен
2. Проверь URL (ws://localhost:8080)
3. Подожди 5 секунд и обнови (F5)

## 🐛 РЕШЕНИЕ ПРОБЛЕМ

### "npm: command not found"
**Проблема:** Node.js не установлен
**Решение:** Установи Node.js с https://nodejs.org

### "Port 8080 already in use"
**Проблема:** Порт занят другим процессом
**Решение:** 
```bash
PORT=8888 npm run server
```

### "Cannot find module 'ws'"
**Проблема:** Зависимости не установлены
**Решение:**
```bash
npm install
```

### "Cannot find module 'better-sqlite3'"
**Проблема:** Нужна компиляция для твоей системы
**Решение:**
```bash
npm install --build-from-source
```

### "Database is locked"
**Проблема:** БД используется другим процессом
**Решение:** Закрой все терминалы с `npm run server` и запусти заново

### Лаунчер не подключается к серверу
**Решение:**
1. Убедись что `npm run server` запущен
2. Проверь URL:
   - Локально: `ws://localhost:8080`
   - Друг в сети: `ws://твой_IP:8080`
   - Railway: `wss://твой-сервер.railway.app`
3. Дождись 5 секунд (может быть задержка)
4. Нажми F5 (обнови страницу)

### "Electron not found"
**Проблема:** Electron не установлен
**Решение:**
```bash
npm install electron --save-dev
npm start
```

## 💡 СОВЕТЫ

1. **Оставляй сервер включённым** - игроки смогут играть пока сервер работает
2. **Смотри консоль сервера** - там видны все ошибки и действия
3. **Обновляй на Railway** - просто сделай `git push`, Railway пересобирается
4. **Бэкапь БД** - копируй `data/legendary-age.db` перед большими обновлениями
5. **Закрывай правильно** - нажми `Ctrl + C` в терминале, не закрывай просто окно
